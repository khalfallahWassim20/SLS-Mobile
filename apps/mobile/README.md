# Application mobile — prototype

Depuis la racine : `npm install`, puis `npm run mobile`. Ouvrir avec Expo Go sur Android, ou utiliser un émulateur Android configuré localement.

Ce prototype est uniquement en français et utilise des données fictives en mémoire. Il permet de choisir un client, consulter des articles, remplir un panier et voir les totaux. Les remises proposées sont limitées à quelques boutons pour la démonstration. Aucun paiement, stockage, facture émise, PDF, synchronisation, authentification ou autorisation administrateur n'est encore disponible. Ne pas utiliser en production.
